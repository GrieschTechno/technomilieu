# AzuraCast Server Setup – NICHT AKTIV

Stand: 27.11.2026

Dieses Dokument ist aus dem aktiven Umsetzungsplan genommen.

**Verbindliche Vorgabe: 100 % gratis.** Es wird kein Hetzner- oder anderer kostenpflichtiger Server bestellt, gemietet oder eingerichtet. Es werden keine Zahlungsdaten benötigt.

AzuraCast ist freie Software, aber ein dauerhaft verfügbarer Host ist für den 24/7-Betrieb erforderlich. Ein kostenloser, geeigneter und dauerhaft verfügbarer Host wurde bisher nicht nachgewiesen.

Der aktuelle Projektweg ist stattdessen:
1. GitHub Pages für die statische Website.
2. Listen2MyRadio bleibt der bestehende Live-Sendepfad für Traktor Pro.
3. Internet Archive als kostenloses DJ-Mix-Archiv.
4. `playlist.json` verbindet veröffentlichte Mix-Dateien mit dem Website-Archivplayer.

Die bisherige Cloud-init-Vorlage und die Serverprofile werden nicht ausgeführt. Es werden keine Änderungen am laufenden Listen2MyRadio-Stream vorgenommen.

Siehe `ARCHIV_ANLEITUNG.md` und `README.md` für den aktuellen Weg.
